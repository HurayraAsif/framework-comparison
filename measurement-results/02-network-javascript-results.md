- `measurement-results/personal-run/browser-javascript-personal.csv`
- `measurement-results/personal-run/browser-javascript-personal-summary.csv`
- `measurement-results/personal-run/browser-javascript-personal.json`
- `notes/personal-browser-javascript-results-2026-07-20.md`
- `measurement-tools/measure-browser-javascript-windows.mjs`

This preliminary file must not be used as evidence for the final thesis tables or conclusions.
