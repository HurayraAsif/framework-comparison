# Product Explorer SVG Assets

These are original SVG product images created for the thesis Product Explorer application.

Copy all SVG files into each framework project's public images folder:

- astro-product-explorer/public/images/
- sveltekit-product-explorer/static/images/
- qwik-product-explorer/public/images/

The filenames match the dataset image paths:
- /images/product-01.svg
- ...
- /images/product-15.svg
